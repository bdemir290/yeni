# Dortnala - Indonesian (id) glossary

Rules: ALL CAPS, A-Z 0-9 and the allowed symbols only (no accents). Player is addressed as KAMU.
Turkish suffixes glued to names/numbers are dropped. Short labels <= Turkish length + 2.
