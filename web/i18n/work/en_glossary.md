## Conventions
- Static percentages read naturally: "SPEED +5%".
- Fragments that end in "+%" before a number from code keep the "+%" order ("BASE SPEED +%" + 6 -> "BASE SPEED +%6"),
  because the code appends the number last and the leading/trailing space rule prevents moving "%" after it.
- Counts from code: prefer "+N STAT" or noun forms that read fine for both 1 and N.
- GRAX = flashy TV host ("FOLKS!", "LADIES, GENTLEBEINGS"); BIP-0 ends lines with "BIP!"/"BIP."; GALE (mother) warm.
