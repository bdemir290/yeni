# Dörtnala - Spanish (es) glossary

Neutral Spanish (Spain + LatAm), ALL CAPS, accents kept (Á É Í Ó Ú Ñ Ü ¿ ¡). Informal "TÚ" toward the player.
Units: SN (saniye) -> S ; SV (seviye) -> NV ; X2 stays.

## Style
- Grax: flashy TV host ("¡DAMAS Y CABALLEROS!", "¡QUÉ ESPECTÁCULO!").
- BIP-0: "¡BIP!" cute robot.
- Mother (ROCÍO): warm, "CARIÑO", "MI VIDA".
- Buttons: shortest natural word (OK, SALIR, ATRÁS, JUGAR, MEJORAR).
